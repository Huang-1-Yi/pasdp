## 检查范围

训练真实使用 `train.py`，不是仅实例化配置。数据为 1013 前两条轨迹，
双相机 240×320 RGB、左右位姿、2+1 维 IO 状态，动作保留采集定义的 15 列。
batch_size=1、1 epoch、最多 1 个训练 batch、num_workers=0、关闭 EMA。
smoke 的 warmup_steps=0，避免唯一的优化器更新处于零学习率预热阶段。
为减少烟测产物，关闭 latest/snapshot/top-k checkpoint 保存。

另在独立进程中初始化同一配置的 policy，使用同一真实数据 batch 和 normalizer，
reset 后连续调用两次 predict_action，检查输出形状和有限性。
这部分是新初始化权重的推理接口检查，不是训练后模型性能评估。
部分训练 workspace 还在 epoch 0 执行了训练样本推理诊断。

## 特殊配置

- DP、SDP、Flow、Focal、Transformer、ACT 使用 TrainPolicyWorkspace。
- Transformer 移除 UNet capacity 配置。
- ACT 移除通用 encoder/capacity，使用模型自身 optimizer、关闭 EMA，
  max_timesteps=1000、n_envs=1、temporal_agg=false。
- BCRNN 使用 TrainBCRNNWorkspace，移除通用 encoder/capacity，
  temporal=bcrnn_h10_obs1_action1，训练输入完整 10 步观测。
- PADP unrolled 使用专用 workspace；模型 H=40、K=2，dataset 读取 41 步动作和 2 步观测。
- 其余沿用 H=40、观测 1 帧、执行 1 步的真机配置。

## 重跑

```bash
cd /media/disk7t/dp_pro6000
/opt/miniconda3/envs/sim_torch27_v8/bin/python scripts/smoke_real_policies.py --gpu 1
```

脚本顺序运行，每次生成独立时间戳目录。单独测试可用 `--methods act bcrnn`。
完整训练须移除 max_episodes=2、max_train_steps=1 等 smoke 限制，并按实验方案
设置 batch、训练预算、EMA、验证和 checkpoint。不能直接把 smoke 命令当正式实验。

没有连接机械臂或相机，没有改动已有 policy/workspace 源码；此次新增的辅助脚本
只用于复现 smoke。测试不证明收敛、真机成功率、长时运行稳定性或原论文完整复现。
