# 服务器 10.242.5.12：卡 2 串行点云对比

服务器只有卡 2 用于本轮实验时，DP、PADP、Focal 必须串行运行。不要分别执行三条
`nohup`，否则三个 batch 128 训练会同时占用同一张卡。

## 1. 登录与检查

```bash
ssh 10.242.5.12
cd /media/disk7t/dp_pro6000

git status --short
conda env list | grep sim_torch27_v8
nvidia-smi -i 2
ls -ld data/metaworld_door-close_expert.zarr
```

如果服务器项目不在该目录，只修改 `cd`。如果数据尚未接入，先根据服务器的数据根目录
执行：

```bash
DP_DATA_ROOT=/实际数据根目录 bash tests/运行命令/链接数据集.sh
```

## 2. 卡 2 前台 smoke

```bash
CUDA_VISIBLE_DEVICES=2 HYDRA_FULL_ERROR=1 \
conda run --no-capture-output -n sim_torch27_v8 \
python -u train_sim.py --config-name=train \
  experiment=focal_metaworld \
  task=metaworld/door-close_pointcloud \
  capacity=smoke recipe=smoke_pointcloud \
  task.env_runner.eval_episodes=1 task.env_runner.max_steps=1 \
  logging.mode=disabled name=smoke_focal_gpu2
```

Smoke 只验证代码、数据和环境链路，不比较成功率。

## 3. 后台串行运行三个算法

先检查队列将要执行的命令，不启动训练：

```bash
DRY_RUN=1 CUDA_VISIBLE_DEVICES=2 CONDA_ENV=sim_torch27_v8 \
bash tests/运行命令/卡2点云对比队列.sh metaworld door-close 42
```

先跑一个 seed：

```bash
mkdir -p run_logs/pointcloud_compare
nohup env CUDA_VISIBLE_DEVICES=2 CONDA_ENV=sim_torch27_v8 HYDRA_FULL_ERROR=1 \
bash tests/运行命令/卡2点云对比队列.sh metaworld door-close 42 \
> run_logs/pointcloud_compare/queue_metaworld_door-close_seed42.log 2>&1 &
echo $!
```

环境、encoder、policy 和输入主轴都完成 seed42 后，最后补 seed43、44：

```bash
nohup env CUDA_VISIBLE_DEVICES=2 CONDA_ENV=sim_torch27_v8 HYDRA_FULL_ERROR=1 \
bash tests/运行命令/卡2点云对比队列.sh metaworld door-close 43 44 \
> run_logs/pointcloud_compare/queue_metaworld_door-close_43_44.log 2>&1 &
echo $!
```

seed42 已有正式结果时不得重复运行；补 seed 阶段只运行 `43 44`。

## 4. 查看进度

```bash
tail -f run_logs/pointcloud_compare/queue_metaworld_door-close_seed42.log
tail -f run_logs/pointcloud_compare/metaworld_door-close/focal_metaworld_door-close_seed42.log
pgrep -af 'train_sim.py.*(compare_(dp|padp)_(metaworld|adroit)|focal_(metaworld|adroit))'
nvidia-smi -i 2
```

队列遇到任一训练失败会停止，并在队列日志末尾打印失败实验日志的最后 100 行。

训练结束后查看每个实验最后一次 rollout 指标：

```bash
find data/outputs -type f -name train_logs.json.txt -print0 |
while IFS= read -r -d '' f; do
  case "$f" in
    *compare_*|*/focal/*) ;;
    *) continue ;;
  esac
  echo "===== $f"
  grep '"mean_success_rates"' "$f" | tail -n 1
done
```

最终对比必须对 DP、PADP、Focal 使用完全相同的任务和 seed，并报告三个 seed 的成功率
均值与标准差；不能比较 smoke 结果。
