# 统一数据软链接

训练配置继续使用项目内的相对路径 `data/...`。当前服务器的数据根目录为
`/media/disk7t/data`。

在项目根目录执行一次：

```bash
cd /media/disk7t/dp_pro6000
DP_DATA_ROOT=/media/disk7t/data bash tests/运行命令/链接数据集.sh
```

脚本会创建：

```text
data/adroit             -> /media/disk7t/data/adroit
data/libero             -> /media/disk7t/data/libero
data/libero_plus        -> /media/disk7t/data/libero_plus
data/libero_plus_assets -> /media/disk7t/data/libero_plus_assets
data/metaworld          -> /media/disk7t/data/metaworld
data/PADP201023          -> /media/disk7t/data/PADP201023
data/robomimic          -> /media/disk7t/data/robomimic

# 兼容当前 MetaWorld / Adroit 配置的任务级平铺链接：
data/metaworld_<task>_expert.zarr -> /media/disk7t/data/metaworld/同名目录
data/adroit_<task>_expert.zarr    -> /media/disk7t/data/adroit/同名目录
```

脚本可重复运行，不会删除或覆盖已有真实数据，也不会替换指向其他位置的软链接。服务器数据根
目录不同时，用环境变量覆盖：

```bash
DP_DATA_ROOT=/实际数据根目录 bash tests/运行命令/链接数据集.sh
```

验证链接：

```bash
readlink -f data/robomimic
readlink -f data/metaworld
readlink -f data/libero
readlink -f data/metaworld_door-close_expert.zarr
readlink -f data/adroit_door_expert.zarr
test -f data/robomimic/datasets/coffee_d0/coffee_d0_abs.hdf5
```

软链接只解决路径映射，不会生成缺失任务的数据。运行文档中的 `run_one` 仍会在启动前检查
具体 HDF5/Zarr 是否存在。

## 输出目录不是输入软链接

Hydra 会自动创建以下实验结果目录，无需把输入数据链接到这里：

```text
data/outputs/dp/
data/outputs/padp/
data/outputs/focal/
```

如果服务器要求写入绝对目录 `/data/output`，先确认当前用户有写权限，并在启动命令追加：

```bash
output_root=/data/output
```

此时结果会分别写入 `/data/output/dp`、`/data/output/padp`、
`/data/output/focal`。该 override 只改变输出位置，不影响输入数据软链接。
