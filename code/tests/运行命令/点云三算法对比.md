服务器 `10.242.5.12` 只使用卡 2 的具体 SSH、smoke、后台串行队列和补跑命令见
[服务器卡2运行](服务器10.242.5.12卡2运行.md)。
PADP 卡 2、Focal 卡 1 的双卡并行命令见
[服务器双卡 PADP/Focal](服务器双卡PADP_Focal运行.md)。

## 1. 固定的对比条件

六个 suite preset（DP/PADP 使用 `compare_*`，Focal 使用 `focal_*`）已把非算法变量固定为：

| 项目 | 正式对比值 |
|---|---|
| 输入 | Focal XYZ PointNet；MetaWorld `1024×3`，Adroit `512×3` |
| 时间窗口 | `horizon=12, n_obs_steps=2, n_action_steps=4` |
| head 配置 | `capacity=base`：`diffusion_step_embed_dim=128, down_dims=[256,512,1024]` |
| 训练预算 | 1000 epoch；每 100 epoch rollout/checkpoint |
| 默认 batch | 点云统一为 128；2080Ti 与 Pro 6000D 不分硬件改默认值 |
| seed | 命令显式传入；三种算法必须使用相同 seed 集合 |

三者使用相同 task、dataset、runner、encoder、时间窗口、容量配置和 recipe；只替换
DP、PADP、Focal Policy。由于三种算法内部 head 实现和训练 workspace 不同，配置宽度相同
不代表参数量绝对相等，结果中应同时记录模型参数量。

正式点云实验只有一套默认训练 recipe：`recipe=pointcloud`。若因显存不足必须覆盖 batch，
应把覆盖记录为单独实验条件，且 DP、PADP、Focal 三条命令必须使用相同值。

## 5. 通用后台函数

```bash
cd /home/hy/dp_pro6000
mkdir -p run_logs/pointcloud_compare

run_one() {
  algo="$1"      # dp | padp | focal
  suite="$2"     # metaworld | adroit
  task="$3"
  seed="$4"
  gpu="$5"

  case "$suite" in
    metaworld)
      data="data/metaworld_${task}_expert.zarr"
      task_cfg="metaworld/${task}_pointcloud"
      ;;
    adroit)
      data="data/adroit_${task}_expert.zarr"
      task_cfg="adroit/${task}_pointcloud"
      ;;
    *) echo "suite 必须是 metaworld 或 adroit"; return 2 ;;
  esac

  if [ ! -e "$data" ]; then
    echo "缺少数据：$data"
    return 2
  fi

  if [ "$algo" = focal ]; then
    experiment="focal_${suite}"
  else
    experiment="compare_${algo}_${suite}"
  fi
  log="run_logs/pointcloud_compare/${algo}_${suite}_${task}_seed${seed}.log"
  nohup env CUDA_VISIBLE_DEVICES="$gpu" HYDRA_FULL_ERROR=1 \
  conda run --no-capture-output -n sim_torch27_v8 \
  python -u train_sim.py --config-name=train \
    experiment="$experiment" task="$task_cfg" \
    training.seed="$seed" training.resume=false \
    training.early_stopping.enabled=false \
    > "$log" 2>&1 &
  echo "algo=$algo suite=$suite task=$task seed=$seed gpu=$gpu pid=$! log=$log"
}
```

三卡并行同一 seed：

```bash
run_one dp    metaworld door-close 42 0
run_one padp  metaworld door-close 42 1
run_one focal metaworld door-close 42 2
```

Adroit：

```bash
run_one dp    adroit door 42 0
run_one padp  adroit door 42 1
run_one focal adroit door 42 2
```

第一阶段所有 unique configurations 只运行 seed42。环境、encoder、policy 和输入主轴都完成
一遍后，再为预先声明的核心矩阵补 seed43/44；单卡必须等待上一实验退出后再启动下一项。

## 6. 查看与验收

```bash
tail -f run_logs/pointcloud_compare/focal_metaworld_door-close_seed42.log
pgrep -af 'train_sim.py.*(compare_(dp|padp)_metaworld|focal_metaworld)'
nvidia-smi
```

比较 `train_logs.json.txt` 中相同 rollout epoch 的 `test_mean_score`、
`mean_success_rates`，最终报告各 seed 的均值和标准差。Smoke 中的 0 成功率没有性能意义。
